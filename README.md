# ジムログ

ジム通い用の筋トレ記録Webアプリ（スマホ向け・インストール可能なPWA）。

- カレンダーで記録日と鍛えた部位をひと目で
- 日付をタップ → その日のメニューを記録（kg × 回数 × セット、ウォームアップ/ドロップ）
- [KONGOU](https://www.kongou-fitness.com/product/) のマシン133機種 + 一般的なフリーウェイト・自重・有酸素
- 前回の記録を自動表示、自己ベスト（PR）表示、推定1RM
- 休憩タイマー、マシンごとの設定メモ（シート位置など）、マイジム★
- 種目別の推移グラフ、部位別セット数、体重グラフ
- ルーティン登録、過去の日からコピー
- データは端末内（localStorage）に保存。設定からバックアップ/復元

ビルド不要の静的サイト。`python -m http.server` で動きます。
